Chat

Ask anything, in Nepali or English. Runs on the offline model on this computer (or the Claude API when a key is set). Nothing is stored.

Try: “Make this email sound friendlier: …”, “Explain burstiness in two lines”, “नेपालीमा एउटा छोटो निबन्ध लेख”.

Settings

Three ways to rewrite: the offline AI model (free, private, one download), the Claude API (best quality, your own key), or plain rules. The five statistical detectors always run offline.

Engine

Offline AI model · no API key, no internet after download

An open-weight language model runs inside Humanizer and does the rewriting on your own computer: Apple GPU on Macs, all CPU cores on Windows. Pick the strongest tier your RAM allows; the app picks it for you and downloads it on first launch.

Any instruct model in GGUF format works (Gemma, Qwen, Llama, Mistral…). Paste the file's direct “resolve/main” link from Hugging Face. Bigger models need more RAM: roughly the file size plus 2 GB.

Claude API · best quality, pay per use

Stored only on this computer, in the app's config folder. Get a key at console.anthropic.com.
